# Persistent Castle Strategy MMO

- **Purpose:** An original mobile strategy MMO about developing heroes and creature forces, completing missions, and attacking persistent player castles through a two-stage guard-and-inner-hero battle.
- **Stage:** Design and planning; no implementation started.
- **Repository:** Not created yet; project setup is a separate future task and requires owner approval.
- **Start a session:** Open Claude Code or Codex CLI with the Workshop `infra/` repository as its working directory and say: “Run `tasks/projects/persistent-castle-mmo/persistent-castle-mmo-planning.md`.” Start a fresh client session if it does not discover the existing game agents.
