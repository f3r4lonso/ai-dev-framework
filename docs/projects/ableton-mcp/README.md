# AbletonMCP

- **Purpose:** Third-party MCP server that lets an MCP-compatible AI assistant compose, arrange, mix, render and analyze music in Ableton Live.
- **Stage:** Evaluation; not cloned or installed.
- **Repository:** [elleural/ableton-mcp](https://github.com/elleural/ableton-mcp)
- **Requirements:** Ableton Live 12.4 or later, Python 3.10 or later, `uv`; `ffmpeg` for audio analysis and release encoding. The project describes macOS as its primary platform and Windows as best-effort.
- **Start a session:** Review the repository and its license before setup. Do not run third-party installers until they have been reviewed.
- **Shared resources it uses:** None configured.
- **Project-specific resources:** In the external repository.
