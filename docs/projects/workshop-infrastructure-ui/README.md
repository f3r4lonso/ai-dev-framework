# Workshop Infrastructure UI

> **Read-only history:** merged into Workshop AI in V1. Continue work in `applications/workshop-ai`, where V2 is built locally and awaits owner acceptance. See
> [workshop-ai-v2/](../../workshop-ai-v2/README.md) and the task
> [workshop-ai-v2-unified-app](../../../tasks/projects/workshop-ai/workshop-ai-v2-unified-app.md).

- **Purpose:** A local browser page (Python stdlib server + React) that shows Workshop resources, offers filtered/collapsible navigation, previews selected documents in the local Spanish reader, and runs explicitly started 2–5 step agent chains through the verified tool-free Claude transport. Console launch buttons remain separate from chains.
- **Stage:** Local MVP, iteration 3: web version (2026-10-19).
- **Repository:** Private repository.
- **Start a session:** Use any coding client with workspace access from the project repository; follow `AGENTS.md`.
