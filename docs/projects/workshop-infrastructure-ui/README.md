# Workshop Infrastructure UI

> **Merging into Workshop AI v2 (approved 2026-10-20; the move happens in increment V1):** this app becomes the Workshop AI user interface. See
> [workshop-ai-v2/](../../workshop-ai-v2/README.md) and the task
> [workshop-ai-v2-unified-app](../../../tasks/projects/workshop-ai/workshop-ai-v2-unified-app.md).

- **Purpose:** A local browser page (Python stdlib server + React) that shows Workshop resources, offers filtered/collapsible navigation, previews selected documents in the local Spanish reader, and runs explicitly started 2–5 step agent chains through the verified tool-free Claude transport. Console launch buttons remain separate from chains.
- **Stage:** Local MVP, iteration 3: web version (2026-10-19).
- **Repository:** Private repository.
- **Start a session:** Use any coding client with workspace access from the project repository; follow `AGENTS.md`.
- **Shared resources it uses:** [Task catalogue](../../catalogues/tasks.md), [agent catalogue](../../catalogues/agents.md), [skill catalogue](../../catalogues/skills.md), [client guides](../../../clients/).
- **Project-specific resources:** in the project repository.
- **Task:** [Unified Workshop Infrastructure UI brief](../../../tasks/projects/workshop-infrastructure-ui/workshop-infrastructure-windows-ui.md) is active with partial delivery; local Ollama translation and manual usability acceptance remain unverified. [Agent-chain design](../../../../applications/workshop-infrastructure-ui/docs/agent-chain-design.md), [interaction decision](../../../../applications/workshop-infrastructure-ui/docs/interaction-upgrade.md), and [architecture](../../../../applications/workshop-infrastructure-ui/docs/web-architecture.md) document current behavior and limits.
