# Workshop Infrastructure UI

- **Purpose:** A local browser page (Python stdlib server + React) that shows everything in the Workshop (tasks, agents, skills, documents, applications, AI-client guides, personal assistants), with global search, "how to use it" text to copy, links to the canonical documents, and buttons that open the Claude Code, Codex, Gemini and Copilot CLIs in the workspace folder. It never writes files.
- **Stage:** Local MVP, iteration 3: web version (2026-10-19).
- **Repository:** Private repository.
- **Start a session:** Use any coding client with workspace access from the project repository; follow `AGENTS.md`.
- **Shared resources it uses:** [Task catalogue](../../catalogues/tasks.md), [agent catalogue](../../catalogues/agents.md), [skill catalogue](../../catalogues/skills.md), [client guides](../../../clients/).
- **Project-specific resources:** in the project repository.
